# Dictyy v0.3.0 Release Notes

## 新功能

- **屏幕取词**：选中任意应用中的英文单词，自动弹出气泡显示释义摘要
- **气泡窗口**：显示单词、音标、简要释义，点击「详细 →」跳转到主界面查看完整内容
- **单词摘要预加载**：启动时将所有单词摘要（约 5 万条）加载到内存，气泡查询瞬时响应
- **快捷键查词**：按 Ctrl+` 时自动查询当前选中的文本，无需手动输入

## 改进

- **词形还原**：支持复数、过去式、进行时等词形变化的自动还原（如 resources → resource、removed → remove）
- **标准日志系统**：迁移到 Rust 标准 log 系统，日志写入 `%LOCALAPPDATA%\Dictyy\logs\Dictyy.log`，支持开发/生产环境自动级别切换
- **气泡位置优化**：根据选中文本位置自动计算气泡显示位置，避免超出屏幕边界
- **智能快捷键行为**：
  - 窗口可见时有选中文本 → 查询新单词（窗口保持显示）
  - 窗口可见时无选中文本 → 隐藏窗口
  - 窗口不可见时 → 显示窗口（有选中文本则查询，无则聚焦输入框）
- **简化 fallback 逻辑**：移除复杂的应用黑名单，只对 Edge PDF 使用 Ctrl+Insert fallback
- **安全性提升**：将剪贴板 fallback 快捷键从 Ctrl+C 改为 Ctrl+Insert，避免在 Terminal 中触发中断信号

## 技术实现

- 屏幕取词采用 UI Automation API 轮询方案（200ms 间隔）
- 选中文本稳定 500ms 后显示气泡，避免频繁弹出
- 气泡与主窗口通过 Tauri 事件机制通信
- 通过进程 ID 检测焦点位置，避免获取自身窗口文本
- 基于进程名（msedge.exe）和元素名模式识别 Edge PDF
